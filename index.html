1. Teoria: Funkcje w Kotlinie

Funkcje w Kotlinie są definiowane przy użyciu słowa kluczowego fun. Oto podstawowa składnia:

fun nazwaFunkcji(parametr: Typ): TypZwrotny {
    // ciało funkcji
    return wynik
}

Kotlin pozwala na funkcje z domyślnymi argumentami, funkcje jednolinijkowe (expression body) oraz funkcje wyższego rzędu.

Ciało: val wynik = a + b

}

5. Fiszki Terminologiczne

Expression Body

Skrócona składnia funkcji, gdzie wynik jest bezpośrednio po znaku równości (np. `fun f() = 1`).

Default Args

Możliwość przypisania wartości domyślnej parametrom w deklaracji funkcji.

Unit

Typ zwracany przez funkcję, która nic nie zwraca (odpowiednik void w innych językach).
